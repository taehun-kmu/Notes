---
title: Permissions by Folder
alias: Linux Permissions by Folder
---

- You can see all properties of all files with the `ls -al` command
- The properties of the file are formed as follows

---

### Command

> `{Type}` `{Permission}` `{Number linked}` `{Owner}` `{Group}` `{Size}` `{Time of last change}` `{Name}`

- `-` : File, `d` : Folder
 
> [!info]- chmod
> 
> > Use when changing permissions
> 
> - **Usage**
>   - `chmod {File Permissions} {File location or name}`

> [!info]- chown
> 
> > Used when changing owners
> 
> - **Usage**
>   - `chown {User to Own} {Groups to Own} {File Location or name}`
