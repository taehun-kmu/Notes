---
title: Structure of the Directory
alias: Linux Structure of the Directory
---

> All directories are made subdirectories of the top-level directory **root**

- **bin** : The folder where the default commands are stored

- **boot** : Folder containing commands related to boot

- **etc** : Folder with almost all configuration files

- **home** : Home folder, folders are created based on the account you're logged into

- **lib** : A folder of libraries used by Linux and various programs.

---

<div style='max-width: 600px; margin: 0 auto;'>

```
root
├─ bin
├─ home
│  ├─ {USER}
│  │  ├─ Desktop
│  │  └─ {Other}
├─ lib
├─ user
├─ boot
└─ etc
```
