title: Types of File Systems
alias: Linux Types of File Systems
---

> [!info] FAT(File Allocate Table)
> 
> - A type of file system that is common on most memory cards in digital cameras and many computer systems.
> - However, the simplicity of the structure can lead to poor space utilization if you have multiple small files.
> - Growing in capacity and highly compatible

> [!info] NTFS(New Technology File System)
> 
> - A new file system for the Windows NT family, created to replace the traditional FAT structure.
> - A file system that is more reliable and more secure than FAT because it can reconstruct disk volumes to a consistent state in the event of system failure or corruption.

> [!info] EXT(EXTended File System)
> 
> - Linux's default file system
> - It is being released in a series as it improves performance,<br>with EXT3 and EXT4 being fully compatible with the secondary extended file system, EXT2, which was used as a base.
> - Starting with EXT3, data retrieval became easier with the use of H-trees (accessed via hashes)<br>to access large directories, and EXT4 was the largest and most massive file system to date.
