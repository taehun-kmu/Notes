---
title: Source Package
alias: Linux Source Package
---

> [!abstract]
> 
> > Package containing **source code** that must be **compiled** into a binary file before it can be executed.
> 
> - This means that source **packages** are also **compiled** when they are installed,<br>which can lead to **long installation times** & **errors** during the compilation process

---

### WHy Use?

> [!NOTE]
> 
> > This is because I can modify the software to do whatever I want with it.
> > Linux has many software packages, most of which are free and open source with GPL licenses.
> 
> - This means you can modify the software if you want, but of course you'll need to download the source package<br>and modify the source code or change the compilation options to use it.
