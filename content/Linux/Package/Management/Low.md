> [!abstract]
> 
> - Tools for installing or removing package files
> 
> <p></p>
> 
> - You can install and uninstall files from each package,<br>but you don't know the dependencies between packages.

> [!info]
> 
> - **Debian** : `dpkg`
> - **Red Hat** : `rpm`
