---
title: Binary Package
alias: Linux Binary Package
---

> [!abstract]
> 
> - Package containing successfully compiled binary files.
> - Because it's already compiled, it takes less time to install and is less likely to introduce errors than a source package.
- Therefore, the default installation packages for Linux are mostly binary packages

---

### Problem

> [!NOTE]
> 
> - This is great because it's already compiled and ready to install, but it can cause problems<br>if your computer's environment is different from the environment the binary package was compiled in.
> > 
> > <p></p>
> > 
> - This means that if a binary package I install requires a specific version of a library to run,<br>and I don't have it, I can't run the program properly.
> 
> > [!info] Package Dependencies
> >
> > - Binary packages require specific libraries or other packages to run properly
